Что такое USN Journal?+

Это журнал изменений файловой системы NTFS. Windows сохраняет в нём записи о создании, удалении, переименовании и других изменениях файлов и каталогов. USN — последовательный номер записи.

Можно ли восстановить удалённый файл?+

Journal Trace помогает найти запись об удалении, если она сохранилась. Журнал не хранит содержимое файла и сам по себе не позволяет его восстановить.

Сайт сканирует мой компьютер?+

Нет. Интерактивный журнал на этой странице использует только встроенный пример. Для чтения настоящего USN Journal нужно приложение для Windows с доступом к NTFS-томам.

Как скачать и запустить Journal Trace?+

Скачайте JournalTrace.exe из релиза JournalTrace и запустите его в Windows — установка не требуется. Для чтения журнала NTFS требуются права администратора. Описание версии доступно на странице релиза на GitHub.
